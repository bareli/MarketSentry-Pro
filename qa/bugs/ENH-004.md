## Summary

Part of the coordinator's "ease first-run setup" brainstorm. The first screen a new user sees
(`STEP_PROVIDER_SCHEMA` in `config_flow.py`, rendered via `config.step.user` in
`translations/en.json`) is a flat list of five providers (Polymarket, Finnhub, Alpaca, CoinGecko,
Exchange rates) with no indication that three of them (Polymarket, CoinGecko, Exchange rates) work
immediately with no account or API key, while two (Finnhub, Alpaca) require leaving HA to create an
external account and generate a key before anything can be tracked. A non-technical first-time user
has no way to tell, from this screen alone, which choice gets them to "I can see this working" the
fastest.

## Recommended change

Add one sentence to `config.step.user.description` (all 8 locale files) calling this out, e.g.:
"Polymarket, CoinGecko and Exchange rates need no account or API key - pick one of those first if
you just want to see it working." No schema/logic change, copy-only.
