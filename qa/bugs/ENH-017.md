## Summary

UX-004 (closed) already addressed the threshold/hysteresis fields' missing units/help text. This
goes further: even with units labeled, a user still has to guess whether e.g. a 2% move threshold
is tight or loose for a specific instrument - a volatile crypto coin and a stable FX pair need very
different defaults, and the form gives no feedback either way.

## Recommended change

Once the instrument is resolved (confirm step already has `ref` and can call the provider), fetch a
short recent price sample and show it as a one-line hint next to the threshold fields (e.g. "AAPL
moved ~1.2% on an average day over the last week") so the default/entered value can be judged
against something real, not a kind-agnostic guess.

## Implementation (2026-10-31, D-033)

`_volatility_hint_pct()` computes a rough average day-over-day absolute change from
`provider.fetch_history(ref, hours=24*7)`, wrapped in its own `asyncio.wait_for(..., timeout=5.0)`
and broad `except Exception`, distinct from the rest of `async_step_confirm` - any provider
failure or timeout degrades to an empty hint, never blocks confirmation. Surfaced via a new
`volatility_hint` `description_placeholders` key.

**i18n gap found and fixed during review (qa-manager, before merge):** the hint sentence was
originally a hardcoded English f-string injected into an otherwise fully-translated confirm
dialog - would show English mid-sentence in e.g. a Hebrew-rendered form (`qa/PROJECT.md` lists
en/he as this product's primary locales). Unlike ENH-003's `persistent_notification` gap, this
wasn't a genuine API limitation - `description_placeholders` fully supports per-locale text, the
original implementation just took the simpler shortcut. Fixed by moving the sentence into
`_VOLATILITY_HINT_TEMPLATE`, a per-language dict covering all 8 shipped locales, keyed off
`hass.config.language.lower()` with a fallback to English for unrecognized codes. Unit convention
kept universal (`"%"`/`"pp"`), deliberately not translated - finance notation, not prose. Commit
`7e40b36`.
