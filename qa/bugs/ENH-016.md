## Summary

The notify-oriented blueprints send a flat `notify.mobile_app_*` message today. HA's mobile app
notify platform supports actionable notification buttons (snooze, open a specific dashboard view,
dismiss and don't alert again for N hours) via the `data.actions` payload - unused here, so every
alert is a plain read-and-swipe-away notification with no quick response.

## Recommended change

Add an optional `data.actions` block (behind a new blueprint input, default off to avoid changing
existing automations' behaviour) offering at least "open dashboard" and "snooze this instrument for
1 hour" - the snooze would need a small `input_boolean`/timer per instrument or a shared cooldown
override, which is the real design question here.

  than pure blueprint-side state
