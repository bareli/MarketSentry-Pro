## Summary

ENH-003 (shipped v0.6.0) nudges a first-time user toward the `custom:marketsentry` dashboard
strategy via a one-time `persistent_notification` with copy-paste YAML. That still requires manually
editing a dashboard, switching to YAML mode, and pasting - the exact friction README's "Auto-
dashboard view" section already describes as advanced HA usage most non-technical users never do.

## Recommended change

Investigate whether HA's dashboard/Lovelace API exposes any way to programmatically add a strategy
view to an existing dashboard (no guaranteed stable public API for this as of this session's HA
knowledge - needs research before promising it), or failing that, a notification action button that
deep-links straight to "add a new view" on the user's default dashboard rather than only describing
the steps in text.

## Relevant files

- `custom_components/marketsentry/config_flow.py` (`_notify_dashboard_strategy`, the ENH-003
  notification this extends)

## Model note

Flagged `model:opus`: needs research into whether HA's frontend/dashboard storage API supports this
at all before any implementation - may turn out infeasible without a frontend-side custom panel,
which would be a much bigger feature than the notification it extends.

None yet - blocked on the feasibility research above.
