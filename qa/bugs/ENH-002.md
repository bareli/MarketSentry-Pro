## Summary

Part of the coordinator's "ease first-run setup" brainstorm, and a natural follow-on once BUG-002
(stub config crashing `setConfig`) is fixed so this state becomes reachable. Once reachable, the
card's own empty-entity message is **"Entity not found or not a MarketSentry Pro instrument:
{entity}"** (`i18n.js`'s `empty_instrument`) - accurate, but a dead end: it doesn't tell a
first-time user (who just dragged this card onto a dashboard before adding any instrument in
Settings) what to do next, unlike the view-strategy's zero-instrument state, which already links
back to "Settings > Devices & services > MarketSentry Pro > Add instrument."

## Recommended change

When `this._config.entity` is empty/falsy specifically (as opposed to a real-but-wrong entity id,
where "not found" is the more useful message), render the same "Add one via Settings > Devices &
services > MarketSentry Pro > Add instrument" pointer the strategy already uses, instead of (or in
addition to) the generic "entity not found" text.
